# Portfolio Site Brief

## Audience
Potential users, collaborators, and employers who want to understand Mr Z's product direction and inspect CleanMaster.

## Primary goal
Make the work feel intentional and product-led, then direct visitors to the CleanMaster GitHub repository.

## Content scope
- Bilingual Chinese/English content with a persistent language switch.
- Mr Z identity: independent maker of approachable Windows utilities.
- One selected project: CleanMaster.
- Product preview uses an original interface concept until the user supplies a real screenshot.
- GitHub profile and CleanMaster repository links.

## Exclusions
- No invented adoption numbers, testimonials, press coverage, pricing, client logos, or performance claims.
- No blog, CMS, contact form, analytics, or deployment automation in this iteration.

## Acceptance criteria
- The page is responsive and directly openable as static HTML.
- Every interactive control works with keyboard navigation.
- Chinese and English content switch together and preference persists locally.
- CleanMaster source link points to `https://github.com/Wei-Zhang09/CleanMaster`.
- The design is original; it may borrow broad editorial principles from huasheng.ai but must not copy its trade dress, wording, logo, project names, metrics, or layout.
